# TCG Market Signals

Weekly `signals.json` feed for TCG Seller Hub. Card names, short quotes, and links to public YouTube videos. Not financial advice.

Schema 1.2.0 (additive): cards carry `first_printed`, `first_printed_set`, `is_new`, `is_reprint` (printed in 2+ distinct paper sets), `reprint_count`, `latest_reprint_set`, `latest_reprint_date`.
